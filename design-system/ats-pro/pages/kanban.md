# Kanban override

- Keep all four pipeline stages visible on wide screens; use stacked/collapsible stages on mobile.
- Dragging is an enhancement. Each candidate must also have a menu/select to change status.
- Candidate detail uses an accessible drawer with labelled tabs and Escape/backdrop close.
- Search and add-candidate actions wrap without overflowing at 375px.
- The page owns its heading inside a charcoal command hero; do not repeat the global masthead.
- Lanes are tinted work regions with a status dot and count, not generic cards with colored top borders.
- Candidate anatomy: status rail, avatar/name/email, date and CV metadata, then one compact stage control.
- Avoid nested rounded cards and a full-size labelled select occupying half of every candidate card.
- Lane accents are slate / orange / green / red for applied / interviewing / hired / rejected.
